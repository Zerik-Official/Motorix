# Motorix

Motorix es una plataforma interna para un taller de reparación de motores de minería pesada. Centraliza clientes, motores y órdenes de reparación, y permite al personal autorizado seguir el avance de cada reparación.

- [Seguridad](security.md): flujo de autenticación, firma de JWT con RS256 y gestión de claves.
