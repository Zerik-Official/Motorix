# Motorix

Motorix is an internal platform for a heavy mining engine repair shop. It centralizes clients, engines and repair orders, and lets authorized staff follow the progress of every repair.

## Contents

- [Getting started](getting-started.md): tool installation, environment variables and running the stack.
- [Architecture](architecture.md): components, communication between services and design decisions.
- [Security](security.md): authentication flow, JWT signing with RS256 and key management.
- [Data model](data-model.md): databases, entities and relationships.
- [Testing and CI](testing.md): test suites, end-to-end scenarios and GitHub Actions workflows.
- [Deployment](deployment.md): images, continuous deployment to the VPS, nginx and Cloudflare.
